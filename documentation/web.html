Web / WASM

The original JavaScript implementation remains the recommended web option; this Rust/WebAssembly adapter is experimental.

Experimental
Choose the web implementation

For production browser use, start with the original QuadQR JavaScript repository and its documentation site. It already has a more optimized web scanner. The Rust/WASM adapter here is a compatibility port.

Architecture

Rust owns the v6 codec, compression, security, scanning, and reliability analysis. JavaScript owns browser camera access, workers, Canvas convenience, and result-object shaping. Build targets are baseline browser, threaded browser with Rayon, and Node.js WASM.

Build and serve

cd packages/quadqr-js
npm run setup:wasm
npm run verify
npm run serve

Open http://127.0.0.1:8080/demo/. Root shortcuts run-wasm-demo.bat and ./run-wasm-demo.sh perform the same flow. Set QUADQR_SKIP_THREADED=1 for a baseline browser and Node build.

Initialize in the browser

import { initWasm } from "./library/browser.js";

await initWasm();                    // automatic
await initWasm({ threads: false }); // baseline
await initWasm({ threads: true });  // require threads

Browser API functions include encoding, matrix decoding, rendering, image scanning, and camera scanning. See the WASM package guide and /demo/browser-smoke.html.

Threading and hosting

Browser Rayon needs SharedArrayBuffer and cross-origin isolation. The local server sets COOP/COEP headers; a service worker helps on static hosts. Automatic initialization falls back to baseline if threads are unavailable. Camera work retains the newest frame instead of queuing stale frames.

Current limits

  • The package is private and is not an npm release.
  • Generated WASM artifacts are built locally, not committed.
  • CommonJS and immediate classic-script global compatibility are not the focus yet.
  • Validate the target browser and camera before relying on this adapter.

The wrapper targets the original quadqr-js 1.5.7 API at a pinned revision. npm run sync:demo fetches only the reference stylesheet.
