Rust checks

cargo fmt --all -- --check
cargo clippy --workspace --all-features -- -D warnings
cargo test --workspace --all-features --release

CI runs formatting, workspace Clippy, and release tests on Linux, Windows, and macOS. Release mode matters for scanner timing.

WASM checks

cd packages/quadqr-js
npm run check:source
npm run build:wasm
npm run verify:wasm
npm run check

npm run setup:wasm installs targets and tools. npm run serve starts the isolated demo. npm run verify combines the checks.

Android and Flutter checks

Build the Android release AAR, then exercise it on a supported ABI. For Flutter run build-flutter.*, then flutter analyze and flutter test in the package. Check camera behavior on real hardware when scanner code changes.

Preview this site

This site is static HTML, CSS, and JavaScript. The full source guides are rendered as local HTML pages. Run python -m pip install -r scripts/requirements-docs.txt and python scripts/build-doc-site.py after editing a guide. Then run python scripts/check-doc-links.py. To preview, serve the repository root with python -m http.server 8765 and open /documentation/. The GitHub Pages workflow builds the guides and deploys this directory on pushes to the default branch.
