A shared format

QuadQR uses four color states per normal cell. Triangle16 divides each body cell diagonally for sixteen states. Format v6, masking, error correction, compression, and security envelopes follow the original JavaScript implementation. Ordinary monochrome QR scanners do not decode QuadQR.

Building for the web?

The original JavaScript implementation remains the recommended web option. The Rust/WASM adapter is experimental and documented here.
