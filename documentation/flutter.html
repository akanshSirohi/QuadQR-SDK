Flutter

Use the Rust engine from Dart through a Flutter package for Android, including a live scanner.

RequirementsPrepareUseCamera

Requirements

Flutter 3.22+, Dart 3.3+, Rust, Android SDK/NDK, and cargo-ndk. This package targets Android API 21+ on arm64-v8a, armeabi-v7a, and x86_64. The plugin specifies compile SDK 36 and NDK 30.0.16248370.

Prepare the package

# Windows
build-flutter.bat

# macOS/Linux
./build-flutter.sh

The script builds native libraries, copies them into the plugin, then runs flutter pub get and flutter analyze if Flutter is installed. Add the package as a local path dependency:

dependencies:
  quadqr_flutter:
    path: ../QuadQR-SDK/packages/quadqr-flutter

Encode, render, and scan

import 'package:quadqr_flutter/quadqr.dart';

final qr = QuadQR.instance;
final code = qr.encodeText(
  'Hello Flutter',
  options: const EncodeOptions(ecc: EccLevel.m),
);
final png = qr.renderPng(code, options: const RenderOptions(imageSize: 720));
final scanned = qr.scanImage(png);
print(scanned.text);

The Dart API also covers compression, encryption, signing, capacity, print guidance, and reliability. Read the full Flutter guide.

Live scanning and release

QuadQRLiveScanner scans in a background isolate and keeps the latest pending frame. On Android, prefer submitYuv420 with plane bytes and strides; submitRgba remains available.

final scanner = QuadQRLiveScanner();
await scanner.start();
scanner.results.listen((result) => print(result.text));
scanner.submitRgba(rgbaBytes, width, height);
await scanner.dispose();

build-flutter-release.bat or ./build-flutter-release.sh creates dist/quadqr-flutter.zip after validation. Run the example in packages/quadqr-flutter/example with flutter pub get and flutter run.
