Android

Ship one AAR with typed Java/Kotlin APIs and the Rust native engine for three Android ABIs.

RequirementsBuildJavaKotlinCamera

Requirements

Install Rust, cargo-ndk, Android SDK/NDK, and JDK 17–23 (21 recommended). The library uses compile SDK 36 and minimum SDK 21. Set ANDROID_HOME or ANDROID_SDK_ROOT; set ANDROID_NDK_HOME if discovery fails.

cargo install cargo-ndk

Build the AAR

GoalWindowsmacOS/Linux
Native librariesbuild-android.bat./build-android.sh
AAR from existing librariesbuild-aar.bat./build-aar.sh
Complete releasebuild-android-release.bat./build-android-release.sh

Outputs: android-libs/<abi>/libquadqr.so and dist/quadqr-android-release.aar. ABIs: arm64-v8a, armeabi-v7a, x86_64. Windows uses Android Studio's JBR when present; QUADQR_JAVA_HOME overrides it.

Java quick start

import io.github.akanshsirohi.quadqr.*;

QuadQR qr = QuadQR.getInstance();
EncodedQr code = qr.encodeText("Hello Android");
byte[] png = qr.renderPng(code, RenderOptions.builder().imageSize(720).build());
ScanResult result = qr.scanImage(png);

Copy the AAR to your app's libs folder and add implementation(files("libs/quadqr-android-release.aar")). Read the Java guide for options, security, signing, and reliability.

Kotlin quick start

import io.github.akanshsirohi.quadqr.*

val qr = QuadQR.getInstance()
val code = qr.encodeText("Hello Android")
val png = qr.renderPng(code, RenderOptions.builder().imageSize(720).build())

See the Kotlin guide for configuration-block helpers and complete API examples.

Camera input

For CameraX/Camera2, use scanYuv420 with Y/U/V plane bytes and their row/pixel strides. This avoids app-side RGBA conversion. scanRgba is also available. Analyze frames off the UI thread and drop stale frames.
