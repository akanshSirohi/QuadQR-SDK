Native core

Rust

Encode and decode matrices, render SVG or PNG, scan images, and use the same v6 format as the JavaScript reference.

InstallEncodeRenderScanFeatures

Add the core

[dependencies]
quadqr = { path = "../QuadQR-SDK/crates/quadqr" }

The crate is currently version 0.1.0 in this workspace. Stable Rust is required.

Encode and decode

use quadqr::{decode_matrix, encode_text, EccLevel, EncodeOptions};

let code = encode_text(
    "Hello QuadQR",
    EncodeOptions { ecc: EccLevel::M, ..Default::default() },
)?;
let decoded = decode_matrix(&code.matrix)?;
assert_eq!(decoded.text.as_deref(), Some("Hello QuadQR"));

Use encode_bytes for binary data. Set high_density: true for Triangle16. Leave version unset for automatic sizing, or constrain it with min_version and max_version. ECC levels are L, M, Q, and H.

Render SVG and PNG

use quadqr::{render_svg, to_png, RenderOptions};

let svg = render_svg(&code, RenderOptions::default())?;
let png = to_png(&code, RenderOptions::default())?;

Rendering supports quiet zones, screen/print presets, styles, and logos. Use get_print_guidance and estimate_safe_logo_size before printing.

Scan images

use quadqr::{scan_buffer, ScanOptions};

let bytes = std::fs::read("quadqr.png")?;
let result = scan_buffer(&bytes, &ScanOptions::default())?;
println!("{:?}", result.text);

Other entry points include scan_file and scan_rgba. The scanner supports finder and rotation recovery, perspective correction, erasures, and soft decoding. Run performance tests in release mode.

Application payloads and features

encode_application_text / encode_application_bytes with ApplicationEncodeOptions add compression, AES-256-GCM encryption, and Ed25519 signatures. Core features are image, image-codecs, compression, security, and parallel.

cargo build -p quadqr --no-default-features
cargo build -p quadqr --no-default-features --features image,compression
cargo run --release -p quadqr-demo

The desktop app offers generation, image and camera scanning, reliability tests, and benchmarks. See all build commands and the public exports.
